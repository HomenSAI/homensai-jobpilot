Installation

Installation, Schritt für Schritt

Die Einrichtung dauert etwa 30–40 Minuten. Führen Sie die Schritte in der Reihenfolge aus. Jeder Schritt sagt Ihnen, was Sie auf dem Bildschirm sehen sollten, damit Sie immer wissen, ob es geklappt hat. Auf Ihrem Computer werden weder Git, Python noch andere Entwicklerwerkzeuge benötigt.

Reihenfolge

Was zuerst kommt: der Agent oder das Archiv?

Zuerst der Agent, dann das Archiv, dann verbinden Sie beides. Der Agent kommt zuerst, weil seine Verfügbarkeit von Ihrem Konto abhängt: Es ist besser, das jetzt herauszufinden, als nachdem Sie alles andere vorbereitet haben. Das Archiv ist nur ein Ordner mit Dateien; es wird nützlich, sobald der Agent es öffnet.

Teil 1 · AgentChatGPT Desktop installieren, anmelden und sicherstellen, dass Codex verfügbar ist. Schritt 1
Teil 2 · ProjektordnerDas Projektarchiv im Browser von GitHub herunterladen und in einen Ordner entpacken. Schritt 2
Teil 3 · Verbinden und startenDen Ordner als lokales Projekt öffnen, Berechtigungen festlegen und den ersten sicheren Start ausführen. Schritte 3–6

Ihre Unterlagen können Sie jederzeit sammeln, sogar vor Schritt 1 (siehe „Unterlagen vorbereiten“ weiter unten). In Schritt 7 erzählen Sie dem Agenten von sich, in Schritt 8 verbinden Sie die Post (optional), in Schritt 9 prüfen Sie die erste Warteschlange; die Schritte 10–13 sind optionale Funktionen und der tägliche Ablauf.

Stand des Pakets. Dies ist ein experimenteller Dokumentations- und Agenten-Ablauf. Prüfungen der Statistikseite belegen nicht den vollständigen Gmail-/Agenten-Zyklus. Prüfen Sie Repository und Versionsnummer, bevor Sie herunterladen: github.com/HomenSAI/homensai-jobpilot.

Vor dem Start

Was Sie brauchen

Computer und Konten

  • Ein Windows-Computer mit Internetzugang.
  • ChatGPT Desktop und ein Konto mit verfügbarem Codex. Zugang und Nutzungsgrenzen von Codex hängen vom Tarif ab; prüfen Sie die aktuellen Bedingungen vor dem Kauf.
  • Ein separates Gmail-Konto für die Jobsuche wird empfohlen, aber nur, wenn Sie die Nachverfolgung per E-Mail möchten.

Ihre Unterlagen

  • Ihr Lebenslauf, Diplome und Zeugnisse in beliebigem Format, falls vorhanden — siehe „Unterlagen vorbereiten“ weiter unten.
  • Oder nur Ihre Stimme: Sie können dem Agenten von sich erzählen, und er schreibt alles auf.
  • Die Sprachen für Bewerbungsunterlagen und Berichte.
  • Ein eigener Ordner für das Projekt, zum Beispiel Documents\HomenSAI-JobPilot.

Für die Arbeit mit lokalen Dateien brauchen Sie ein lokales Codex-Projekt, das auf Ihrem Computer geöffnet ist. Ein gewöhnliches Cloud-Projekt in ChatGPT gewährt keinen Zugriff auf einen Ordner auf Ihrem Computer.

Vorbereiten

Unterlagen vorbereiten — das können Sie zuerst tun

Das Projekt-ZIP enthält einen fertigen Ordner Локальные_данные\Положите_сюда („hier ablegen“) mit fünf Unterordnern. Nur dorthin müssen Sie selbst etwas legen. Füllen Sie ihn direkt nach Schritt 2 oder sammeln Sie die Dateien schon jetzt und kopieren sie später. Bereiten Sie nichts vor, fragt Sie der Agent alles selbst (Schritt 7).

Lebenslauf- und Anschreiben-Vorlagen

Alles zu Lebensläufen und Anschreiben legen Sie in zwei Ordner. Der Agent arbeitet damit; die Vorlage, die Sie nennen, dient für Versände.

  1. Material ablegen

    Alles zu Lebensläufen in 4_Шаблон_резюме, alle Anschreiben in 5_Шаблон_сопроводительного_письма. Jedes Format, auch alte Fassungen. Nur lesen.

  2. Entwürfe prüfen

    Der Agent erstellt einen Lebenslauf-Entwurf und einen Anschreiben-Entwurf mit der Quelle jedes Fakts sowie eine Liste älterer Fassungen. Sie prüfen sie.

  3. Vorlage nennen

    Nennen Sie den Lebenslauf und das Anschreiben, die Sie jetzt verwenden. Diese werden zur Vorlage für Versände.

  4. Word-Kopie und Seitenprüfung

    Die Vorlage wird zu einer bearbeitbaren Word-Arbeitskopie in Resume bzw. CoverLetter. Jede Seite wird mit dem Original-PDF verglichen: Seitenzahl, Größe, Text, Position, Bilder und Schriften. Den Vergleich sehen Sie vor der Bestätigung. Ein Unterschied wird gemeldet, und der Agent fragt, was zu tun ist.

Noch keine Vorlage?

  • Der Agent bietet drei Layoutvarianten zur Auswahl an
  • oder Sie senden Ihre eigene Vorlage in Ordner 4 bzw. 5

Foto im Lebenslauf

  • Nur auf Ihre Wahl: oben rechts auf der ersten Seite, standardmäßig 30 × 40 mm. Eine andere Größe ist möglich; die Proportionen bleiben erhalten.

Originale werden nie verändert. Pfade und Prüfsummen der gewählten Vorlagen werden je Profil gespeichert; für jede neue Stelle entstehen neue Dokumente.

Erzählen Sie Ihre Geschichte per Sprache

  1. Öffnen Sie einen Chat mit Claude oder ChatGPT und schalten Sie den Sprachmodus ein (das Mikrofon-Symbol).
  2. Sagen Sie: „Ich erzähle dir von mir für meinen Lebenslauf. Stell mir Fragen, jeweils nur zu einem Thema. Schreib am Ende meine Geschichte Wort für Wort auf, ohne etwas hinzuzufügen, als Textdatei.“ Sie können die Fragen aus Вопросы_для_рассказа.md einfügen.
  3. Sprechen Sie so lange Sie möchten, in Teilen, an verschiedenen Tagen, in beliebiger Reihenfolge. Wenn Sie sich an etwas nicht erinnern, sagen Sie es.
  4. Speichern Sie die Textdatei im Ordner 2_Рассказ_о_себе.

Oder lassen Sie sich vom Agenten fragen

Bereiten Sie nichts vor. Starten Sie bei Schritt 6 den Agenten in Ihrem Projektordner und sagen Sie, dass Sie von sich erzählen möchten, per Sprache oder Text. Er stellt die Fragen jeweils zu einem Thema, speichert Ihre Antworten Wort für Wort im Ordner 2_Рассказ_о_себе und erstellt daraus Ihre Wissensbasis.

Der Agent liest diese Ordner nur; er ändert, verschiebt oder löscht Ihre Dateien nie. Alles bleibt auf Ihrem Computer und wird nicht veröffentlicht (der Ordner Локальные_данные ist von Git ausgeschlossen). Aus Ihren Dateien und Ihrer Geschichte schreibt der Agent Ihre Wissensbasis: eine Datei mit Ihrer ganzen Lebensgeschichte als Angaben (Локальные_данные\persons\<Ihre ID>\База_знаний\Жизнеописание.md). Er zeigt Ihnen jede Angabe zur Bestätigung, und Lebensläufe und Anschreiben verwenden nur bestätigte Angaben.

Teil 1

Der Agent

  1. ChatGPT Desktop installieren und anmelden

    1. Öffnen Sie die offizielle Download-Seite von ChatGPT.
    2. Laden Sie die Windows-Version herunter, installieren und starten Sie sie und melden Sie sich an.
    3. Wählen Sie im Modus-Auswahlfeld Codex. Wählen Sie nicht ein Cloud-Projekt von ChatGPT oder „Work“: Dieser Ablauf braucht einen geöffneten lokalen Ordner.

    Sie sollten sehen: das Hauptfenster mit Ihrem Kontonamen und einem Modus-Auswahlfeld, das Codex enthält.

    Wenn Codex fehlt: prüfen Sie, ob es für Ihr Konto und Ihre Organisation verfügbar ist. Installieren Sie keine inoffiziellen Versionen. Siehe die Kurzanleitung von OpenAI.

Teil 2

Der Projektordner

  1. Projektarchiv herunterladen und entpacken

    1. Öffnen Sie das Projekt-Repository auf GitHub (github.com/HomenSAI/homensai-jobpilot) im Browser.
    2. Wählen Sie Code → Download ZIP.
    3. Legen Sie im Explorer einen Ordner an, zum Beispiel Documents\HomenSAI-JobPilot.
    4. Entpacken Sie das ZIP in diesen Ordner.
    5. Entpacken Sie nicht in einen Systemordner von Windows.

    Sie sollten sehen: im Ordner direkt (nicht in einem weiteren Ordner): README.md, USER_GUIDE.md, AI_BUILD_SPEC.md, AGENTS.md, CLAUDE.md, TODO_FOR_AI.md, dashboard_template und den Ordner Локальные_данные\Положите_сюда mit fünf Unterordnern.

    Wenn die Dateien eine Ebene tiefer liegen: Sie haben in einen zusätzlichen Unterordner entpackt. Verschieben Sie den Inhalt nach oben oder wählen Sie in Schritt 3 den inneren Ordner.

    Der Ordner enthält sowohl die Projektanweisungen als auch Ihre lokalen Arbeitsdaten. Persönliche Profile, Lebensläufe, E-Mails, OAuth-Token und Statistiken dürfen niemals auf GitHub veröffentlicht werden.

Teil 3

Den Agenten mit dem Ordner verbinden und starten

  1. Ein lokales Projekt anlegen und den Ordner wählen

    1. Öffnen Sie Projects in Codex.
    2. Wählen Sie Add local project oder Open folder (die genaue Bezeichnung hängt von der Version ab).
    3. Wählen Sie den vollständigen Pfad des entpackten Ordners, zum Beispiel C:\Users\IhrName\Documents\HomenSAI-JobPilot.
    4. Gibt es bereits ein Projekt: dessen Menü → Edit project → Add folder, Ordner wählen und Make primary wählen.
    5. Benennen Sie das Projekt, zum Beispiel Jobsuche.

    Sie sollten sehen: das Projekt in der Liste, und als Hauptordner den, der README.md enthält — nicht eine einzelne Datei und nicht einen übergeordneten Ordner mit fremden Daten.

    Wichtig: Der Satz „arbeite im Pfad …“ im Chat reicht nicht. Der Ordner muss als lokaler Ordner des Projekts geöffnet oder angehängt werden. Siehe lokale Projekte.

  2. Einen Einrichtungs-Chat anlegen

    1. Öffnen Sie Ihr neues lokales Projekt und wählen Sie darin New chat (neuer Chat).
    2. Prüfen Sie, dass Codex und die lokale Umgebung (Local / This computer) gewählt sind, nicht Cloud oder Worktree.
    3. Benennen Sie den Chat, zum Beispiel Erste Einrichtung JobPilot.

    Sie sollten sehen: einen Chat im Projekt mit „Local“ neben dem Eingabefeld.

    Sie können für Einrichtung, Suche, tägliche Prüfungen und Monatsberichte getrennte Chats verwenden. Die Dateien und das Journal des Projekts halten den Stand zwischen den Chats; verlassen Sie sich nicht auf den Verlauf eines einzelnen Gesprächs.

  3. Die Berechtigungen festlegen

    1. Öffnen Sie das Berechtigungsmenü unter dem Nachrichtenfeld und wählen Sie Ask for approval (Genehmigung anfordern). Der Agent kann dann im aktuellen Ordner arbeiten und fragt vorher bei allem Weiteren nach.
    2. Fehlt die Einstellung, schauen Sie unter Settings → General → Permissions (Einstellungen → Allgemein → Berechtigungen).
    3. Wählen Sie nicht Full access (Vollzugriff), starten Sie ChatGPT Desktop nicht als Administrator und geben Sie keinen Zugriff auf das ganze Laufwerk.
    4. Verlangt Codex Zugriff außerhalb des Ordners, überlegen Sie zuerst, ob er wirklich nötig ist. Erteilen Sie nur eine enge, einmalige Berechtigung.
    5. Websuche, Dateien, E-Mail und Bildschirmsteuerung sind getrennte Berechtigungen. Die Erlaubnis für eine erlaubt nicht die anderen.

    Sie sollten sehen: „Ask for approval“ (oder das Entsprechende) im Berechtigungsmenü und den Projektordner als Arbeitsordner.

    Offizielle Erläuterungen: Berechtigungsmodi, Sandboxing.

  4. Den ersten sicheren Start durchführen

    Geben Sie dies in den neuen Chat ein (oder einfach „Start“):

    Start. Read AGENTS.md and TODO_FOR_AI.md and lead me through the first run.

    Der Agent lädt seine Regeln selbst (Codex liest AGENTS.md, Claude Code liest CLAUDE.md). Er stellt sich vor, bestätigt den Arbeitsordner, prüft seine Werkzeuge und fragt Sie dann, jeweils eine Frage: Ihren Namen und die Sprache, die Sie bevorzugen. Danach bittet er um Ihre Zustimmung, Ihre persönlichen Unterlagen zu lesen, und beginnt die erste Einrichtung (Schritt 7). Antworten Sie mit eigenen Worten, per Sprache, wenn Ihre App eine Mikrofontaste hat.

    Sie sollten sehen: Der Agent nennt den richtigen Ordner, erklärt in wenigen Zeilen, was passieren wird, sagt, dass er im Entwurfsmodus arbeitet, und stellt seine erste Frage.

    Wenn der Agent nicht weiß, was er tun soll, oder sagt, AGENTS.md oder TODO_FOR_AI.md fehle: Der Ordner ist falsch oder das Archiv unvollständig. Prüfen Sie die Schritte 2 und 3. Bitten Sie den Agenten nicht, fehlende Dateien zu erfinden.

Teil 4

Ihre Daten, die Post und die erste Warteschlange

  1. Die erste Einrichtung: der Agent fragt, Sie antworten

    Ab hier führt der Agent. Es gibt kein Formular: Er stellt eine Frage nach der anderen und speichert jede Antwort in Dateien. Die Reihenfolge ist immer dieselbe:

    1. Zustimmung. Bevor er etwas Persönliches liest, erklärt er, dass ein Cloud-Agent das Gelesene an seinen Anbieter weitergeben kann, und bittet um Ihre Zustimmung. „Lokal gespeichert“ heißt nicht „offline verarbeitet“. Sie können Nein sagen und mit einem anonymisierten Beispiel beginnen.
    2. Ihre Geschichte. Er sagt Ihnen, wohin Ihre Geschichte gehört: in den Ordner Локальные_данные\Положите_сюда\2_Рассказ_о_себе. Haben Sie keine, bietet er an, sie sofort vorzubereiten, komplett per Sprache: Mikrofon einschalten und über Ihr ganzes Leben sprechen. Er unterbricht nicht und speichert jedes Wort.
    3. Ihre Unterlagen. Er fragt, ob Sie einen Lebenslauf, Diplome, Zeugnisse, Kursnachweise oder Referenzen haben. Legen Sie alles in 1_Мои_документы (Fotos und Scans sind in Ordnung) und sagen Sie „fertig“. Keine Unterlagen? Sagen Sie es, und Sie machen weiter.
    4. Analyse. Er liest alles und schreibt Ihre Wissensbasis. Danach fragt er nach dem, was fehlt, jeweils zu einem Thema: Zertifikate, Kurse, Sprachniveaus, Fähigkeiten, konkrete Situationen, Führerschein und Auto.
    5. Bestätigung. Er zeigt die Angaben Abschnitt für Abschnitt. Sagen Sie zu jeder: richtig, korrigieren oder falsch. Er erfindet nie Erfahrung, Daten, Zeugnisse oder Sprachniveaus. Eine Angabe ohne Dokument bleibt gültig und ist als „Selbstangabe“ markiert.
    6. Die Suche. Er fragt, was wir suchen (Job, Ausbildung, Praktikum, Probearbeit, Zeitarbeit), welche Berufe und Branchen, wo Sie wohnen, den Umkreis in Kilometern, wie Sie hinkommen (Auto, Zug, Bus oder Straßenbahn, Fahrrad, zu Fuß — beliebige Kombination), wie lange der Weg dauern darf, Umstiege, Fußweg und die Rückkehr am Abend, bevorzugte Städte, die Sprachen von Lebenslauf, Anschreiben, E-Mail und Bericht (jeweils getrennt), wie die Bewerbungen verteilt werden sollen und ob Sie eine Berichtsvorlage haben (3_Шаблон_отчёта).
    7. Gespeichert. Er wiederholt alle Ihre Antworten; Sie sagen „richtig“. Die erste Einrichtung ist abgeschlossen, und ab jetzt arbeitet er mit diesen gespeicherten Dateien.

    Sie sollten sehen: die Datei Локальные_данные\persons\<Ihre ID>\База_знаний\Жизнеописание.md mit Ihrer Lebensgeschichte als Angaben, jede mit confirmed oder self-reported markiert, und die Datei Локальные_данные\profiles\<Suchrichtung>\profile.json mit Ihren Sucheinstellungen. Beide können Sie in jedem Texteditor öffnen und lesen.

    Niemals Passwörter, Einmalcodes oder OAuth-Token in eine Datei schreiben. Private Notizen bleiben als sensibel markiert und gehen ohne Ihre ausdrückliche Wahl nie in einen Lebenslauf. Prüfen Sie, dass Локальные_данные/ von der Veröffentlichung ausgeschlossen ist. Mehrere Suchrichtungen einer Person teilen sich ein Limit von 44 Bewerbungen pro Monat.

  2. Gmail über einen zugelassenen Connector oder den integrierten Browser verbinden

    1. Fragen Sie den Agenten, welche Gmail-Optionen in Ihrer Codex-Installation verfügbar sind. Wählen Sie einen vorhandenen, offiziell zugelassenen Connector oder den integrierten Browser; fügen Sie keinen beliebigen Server hinzu.
    2. Bei einem Connector folgen Sie seinem offiziellen Anmeldeverfahren. Für den Browser bitten Sie Codex, https://mail.google.com zu öffnen, und sagen Sie ihm, dass er noch nicht lesen oder senden soll; melden Sie sich dann selbst an und prüfen Sie die Gmail-Adresse des Profils.
    3. Beim Browser öffnen Sie Settings → Browser → Agent permissions. Ist Computer Use nötig, aktivieren Sie es über Codex → Plugins → Computer Use und erlauben Sie nur den Browser. Beim Connector prüfen Sie das Konto und die getrennten Lese- und Sendeberechtigungen.
    4. Beginnen Sie mit reinen Lesetests. Senden und Terminieren brauchen eine eigene Freigabe. Erlauben Sie niemals das Löschen, das Archivieren in Gmail, das Verschieben von Nachrichten oder das Ändern von Labels.

    Sie sollten sehen: genau die Gmail-Adresse, die Sie vorgesehen haben. Die Browser-Sitzung kann ablaufen; sie ist kein im Projekt gespeichertes Token.

    Anhänge: Der integrierte Browser kann Datei-Uploads nicht automatisieren; ein zugelassener Connector kann das unter Umständen, das ist zu prüfen. Wenn nicht, hängen Sie Lebenslauf und Anschreiben selbst an und prüfen Sie sie in Gmail. Funktioniert keiner der Wege, verwenden Sie EMAIL_TO_SEND.txt und den Explorer. Siehe integrierter Browser und Computer Use.

  3. Die erste Warteschlange vorbereiten und prüfen

    1. Bitten Sie den Agenten, Unternehmen und Stellen in Ihrem Umkreis zu suchen und Quellen, Kontakte, Anforderungen und Prüfdaten zu sammeln.
    2. Prüfen Sie die Einträge, Dubletten, Adressen und ob die Stellen noch offen sind. Prüfen Sie die tatsächlichen Wege für Ihr Verkehrsmittel.
    3. Bitten Sie um ein passgenaues Unterlagenpaket in der gewählten Sprache und prüfen Sie dann jedes Datum, jede Angabe, jeden Empfänger und jeden Anhang.
    4. Prüfen Sie die Warteschlange und bestätigen Sie Termine und Abstände. Aktivieren Sie keinen Massenversand.
    5. Das System erlaubt höchstens 44 Bewerbungen mit Lebenslauf pro Person und Kalendermonat. Lässt sich das verbleibende Kontingent nicht prüfen, muss der Agent anhalten.
    6. Verwenden Sie den Entwurfsmodus, bevor Sie etwas senden. Versand ist erst erlaubt, wenn das Profil eingerichtet und die konkrete Nachricht geprüft ist.

    Sie sollten sehen: Entwürfe in den Monatsordnern und eine Warteschlange mit genauen Terminen und einem Zähler für die verbleibenden Plätze.

    Meldet der Agent „Sendeergebnis unbekannt“, bitten Sie ihn nicht einfach, erneut zu senden: Vergleichen Sie zuerst mit dem Ordner SENT (Gesendet) bzw. mit der Bestätigung im Portal. Ein geänderter Anhang oder Empfänger braucht eine neue Prüfung. Das Standardlimit für den Betreff beträgt 50 Zeichen einschließlich Leerzeichen; das ist eine Regel des Produkts, keine Grenze des E-Mail-Dienstes.

Teil 5

Optionale Funktionen und tägliche Arbeit

  1. Bildschirmsteuerung nur bei Bedarf einschalten

    Suche und Dateiverwaltung brauchen normalerweise keine Mausteuerung. Wenn eine Aufgabe wirklich einen Browser oder ein anderes Fenster braucht:

    1. Öffnen Sie in ChatGPT Desktop Codex → Plugins → Computer Use und installieren oder aktivieren Sie es, falls Ihre Version das hat.
    2. Öffnen Sie Settings → Computer Use und erlauben Sie nur die Anwendung, die Sie brauchen.
    3. Unter Windows halten Sie das gesteuerte Fenster auf dem aktiven Desktop sichtbar.
    4. Genehmigen Sie nur Aktionen, die Sie verstehen. Computer Use ersetzt weder OAuth, den Ordnerzugriff noch die Zustimmung zum Versand.

    Siehe Computer Use. Der Grundablauf braucht es nicht.

  2. Tägliche Arbeit und Terminierung

    Für eine manuelle Prüfung öffnen Sie das lokale Projekt, starten einen Chat Daily check (tägliche Prüfung) und bitten den Agenten, die Regeln zu lesen und den nächsten sicheren Planpunkt zu erledigen. Standardmäßig findet die Prüfung jeden Tag um 16:00 Uhr in Ihrer Zeitzone statt. Am Anfang eines neuen Monats fragt der Agent einmal, ob er die Pakete und den Versand für diesen Monat vorbereiten soll.

    Sie können ChatGPT Desktop/Codex bitten, eine wiederkehrende Aufgabe für dasselbe lokale Projekt anzulegen. Prüfen Sie, dass sie unter Scheduled (geplant) erscheint, und sehen Sie sich das erste Ergebnis an. Für lokale Dateien muss der Computer eingeschaltet bleiben, ChatGPT Desktop laufen und der Ordner verfügbar sein. Unter Windows braucht Computer Use ein sichtbares Browserfenster und kann den Vordergrund übernehmen. Ist eine wiederkehrende Aufgabe oder der Browserzugriff nicht verfügbar, führen Sie die Prüfung manuell aus. Siehe Geplante Aufgaben.

    Nachgeholte Bewerbungen werden nicht als Sammelversand verschickt. Gmail-Nachrichten im Status „Scheduled“ können unabhängig vom Agenten weiterhin versendet werden.

  3. Ihre Statistik öffnen und einen Bericht erstellen

    1. Öffnen Sie nach einer Prüfung Локальные_данные\dashboard\index.html, das lokale Profilmenü. Jedes Profil hat Links zu Statistik und Bereitschaft. Ein Server ist nicht nötig.
    2. Die Statistik zeigt Jahre, Monate und Tage, mit Sortierung nach Datum und Ergebnis sowie Filtern. Die Bereitschaftsseite zeigt geprüfte Einrichtungspunkte, eine Anzeige von 0–100 % und private Links zu Ihren Dokumenten. Beide sind nur lesbar; der Agent aktualisiert sie.
    3. Am Ende des Zeitraums bitten Sie den Agenten um DOCX- und PDF-Dateien in der gewählten Sprache und Vorlage. Ohne eigene Vorlage verwendet er die neutrale Monatstabelle. Der Agent muss das DOCX rendern, jede Seite prüfen und das passende PDF exportieren.
    4. Prüfen Sie Ihren Namen, den Berichtszeitraum, die Zeilen und den kurzen Grund jeder Antwort. Bewerbungen ohne Antwort stehen im Bericht als „keine Antwort erhalten“ in der Berichtssprache.
    5. Der Bericht wird lokal gespeichert. Die tägliche E-Mail-Zustellung an Sie ist eine optionale, gesondert freigegebene Einstellung; Berichte gehen ohne gesonderte Anweisung nicht an Arbeitgeber oder Behörden.

    Die Statistik unterscheidet die Zahl der Antwortnachrichten von der Zahl der Bewerbungen, die eine Antwort erhalten haben. Eine Antwort auf eine ältere Bewerbung zählt in dem Monat, in dem sie eingegangen ist. Eine Absage ohne Begründung lautet „Grund nicht angegeben“. Eine eigene PDF-Seite enthält eine Marktempfehlung mit Datum, Umkreis, Verkehrsmittel, geprüften Quellen und Abdeckung; nicht verfügbare Schätzungen sind entsprechend markiert.

  4. Das Paket aktualisieren und Ihre Daten sichern

    Kopieren Sie vor dem Aktualisieren Локальные_данные/ in einen eigenen Sicherungsordner. Laden Sie das neue ZIP in einen neuen Ordner herunter, vergleichen Sie Versionen und Anweisungen, und bitten Sie den Agenten, nur bestätigte Einstellungen zu übernehmen. Entpacken Sie ein Update nie über Ihren persönlichen Daten und veröffentlichen Sie nie Локальные_данные/.

Umfang

Was nicht umgesetzt ist

JobPilot ist eine experimentelle Sammlung von Prompts und schriftlichen Verfahren für einen externen KI-Agenten, keine eigenständige Anwendung für die Stellensuche oder den E-Mail-Versand.
