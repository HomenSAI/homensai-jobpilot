01 · Heute

Was vorhanden ist

Fertig

  • Die Regeln für den Agenten: Spezifikation, Architektur, Datenvertrag und Abnahmeszenarien, auf Englisch, Russisch und Deutsch.
  • Die Anweisungsdateien für den Agenten als Entwürfe (AGENTS.md, CLAUDE.md, TODO_FOR_AI.md), die fertigen Ordner für Ihre Unterlagen und das Format der Wissensbasis.
  • Diese bebilderte Übersicht und die Schritt-für-Schritt-Anleitung zur Installation.
  • Die Statistikseite: geprüfte Snapshots, historische Stichtage, leere Monate, Anzeige des gemeinsamen Kontingents und Sortierung nach Ergebnis. Ein lokaler VM-Regressionslauf meldet 18 gezielte Prüfungen als bestanden; das ist kein vollständiger Browser- oder Agententest.
  • Betriebsanforderungen für die Monatsvorbereitung, die Terminierung in Gmail mit manuellem Ersatzweg, Archive, tägliche Prüfungen und Berichte, Bereitschaft und Berichtswesen; getrennte Lizenzhinweise für Code und Dokumentation.

Noch nicht erledigt

  • Die Anweisungsdateien für den Agenten (AGENTS.md, CLAUDE.md, TODO_FOR_AI.md) in der Praxis erproben: mit jemandem, der nichts vorbereitet hat, mit jemandem, der die Ordner gefüllt hat, und mit einem Sprachinterview.
  • Eine Gmail-Verbindung und ihre genaue Einrichtung prüfen.
  • Die Abnahmeszenarien von Hand auf synthetischen Daten durchführen.
  • Vollständige Abnahme des Agenten-Ablaufs, von Gmail, Dokumentenrendering und Terminierung mit echten Nutzern.
  • Automatisierte Freigabe- und Datenschutzprüfung sowie vollständige Einrichtungsprüfung in Claude Code.
Verlauf

Versionsverlauf

Wird bei jeder Veröffentlichung aus dem Änderungsprotokoll erzeugt. Die vollständige Historie steht im Änderungsprotokoll.

  1. 1.16.0 · 10 October 2026
    Every employer reply is now saved in full into the application folder, in a new file Replies.txt («Ответы»). For each incoming message the agent writes the sender name and address, Reply-To, Message-ID, date and time with the time zone, the sending IP address and the Received chain, authentication results, subject, recipients, the full text verbatim, and the attachments (name, type, size) or “no attachments”. What the mail tool does not provide is written as “not provided by the mail tool”, nothing is guessed. Earlier blocks are never rewritten, and a message is added once. The journal line mail_received carries the file path and the checksums of the headers and of the text. This is a new capability, so the minor number is raised. On the architecture page, diagram 2 is renamed “Six checks before sending” and rewritten in plain words (what each check does and what happens when it fails), and diagram 3 now says that the daily maximum is only a ceiling, not a minimum number of sending days; all four languages.
  2. 1.15.1 · 10 October 2026
    The templates block in the Prepare section is redesigned in the site style: four numbered steps, two cards (“No template yet?” and “A photo on the CV”) and a note that the originals are never changed. The block is taken out of a nested card where it sat untidily. This is a layout change without new capabilities, so the patch number is raised.
  3. 1.15.0 · 10 October 2026
    An index page index.html is added at the root: all pages and documents in one place, with a block for each language edition (EN, RU, DE, UK). It is the page to open first, so it is clear where to start. This is a new part of the documentation, so the minor number is raised.
  4. 1.14.5 · 10 October 2026
    Every HTML page now shows a version badge in the top-left corner, for example v1.14.5, so a screenshot shows which version is open. The number comes from the VERSION file and is updated at every release by a step of the release workflow. This is a visible label without new capabilities, so the patch number is raised.
  5. 1.14.4 · 10 October 2026
    The Prepare section of the install page gets a block on the CV and cover-letter templates: what to put into folders 4 and 5, how the agent prepares drafts, how a template for mailings is chosen, what happens without a template, how a PDF is checked and when a photo appears. The block is in all four languages. This is a text change without new capabilities, so the patch number is raised.
  6. 1.14.3 · 10 October 2026
    The language switcher on the overview pages shows all four languages (EN, RU, DE, UK) without shrinking. The buttons no longer compress in a narrow row or get clipped on scaled screens. This is a visual fix without new capabilities, so the patch number is raised.
05 · Als Nächstes

Was noch zu tun ist

  • Die Anweisungsdateien in Codex und in Claude Code erproben und korrigieren, was die Agenten falsch verstehen.
  • Ein erster vollständiger Test auf synthetischen Daten, von Hand in einem Chat: Profil → Ziel → Paket → Plan → simulierte Antwort → Bericht und Offline-HTML.
  • Prüfungen unterbrochener Arbeit und von zwei gleichzeitig schreibenden Chats.
  • Danach Gmail-Lesen und kontrollierter Versand mit Nachweisprüfungen. Jedes Profil wählt den Entwurfsmodus, die Freigabe jeder Nachricht oder — mit akzeptierter Einschränkung — eine automatische Warteschlange.
  • Quellen für Stellen und Wege sowie deren Nutzungsbedingungen.
  • Geplante Agentenläufe, wo verfügbar; die manuelle Wiederaufnahme muss für sich allein funktionieren.
  • Rechte- und Datenschutzprüfungen vor der Veröffentlichung.
