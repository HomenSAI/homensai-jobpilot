# История изменений

[English](../../CHANGELOG.md) | [Русский](CHANGELOG.md)

Версия проекта записана в файле [VERSION](../../VERSION). Пока программы нет, версия относится к комплекту документации и странице статистики; с первого рабочего кода это версия выпуска целиком.

Правила: `MAJOR.MINOR.PATCH`. MAJOR меняется, когда формат данных или правила изменились так, что старые данные не подходят. MINOR — новая функция или новая часть документации. PATCH — исправление или правка формулировок без новых возможностей. Каждое изменение в `main` добавляет строку сюда; номер повышается при выпуске. Каждый выпуск получает git-тег `vX.Y.Z`.

## 1.2.0 — 07.10.2026

Первый выпуск с тегом. Документация и страница статистики; рабочей программы ещё нет.

- Иллюстрированный обзор разбит на короткие страницы с меню (обзор, установка, профиль, архитектура, безопасность, рынок, план работ) на английском и русском, в стиле homensai.com и HomenS.AI Core: светлая и тёмная тема, переключатель языка, кнопка «Наверх», ссылки на автора на каждой странице. Шрифты IBM Plex включены в проект (SIL OFL 1.1).
- Новая страница статистики `dashboard_template/index.html`: год → месяц → день, сортировка по дате и по результату (успешно / неуспешно), фильтры, поиск, EN/RU. Показывает только синтетические примеры данных.
- Уточнён порядок установки: сначала агент, потом архив проекта, потом соединение. Пошаговое руководство есть в виде веб-страницы (`overview_install.html`) и в `USER_GUIDE.md`; правила для ИИ-агента — в разделе 10.1 `AI_BUILD_SPEC.md`.
- Формулировки: «автор идеи и разработчик» вместо «предполагаемого разработчика»; простой язык от третьего лица в README и REVIEW; видеообзор убран.
- Корневые `AI_BUILD_SPEC.md` и `DATA_CONTRACT.md` теперь английские (раньше это были русские копии); русская редакция — в `docs/ru`.
- `ARCHITECTURE.md`, `DATA_CONTRACT.md`, `ACCEPTANCE_TESTS.md`: контракт страницы статистики и сценарий DASH-05.
- Содержание документации 1.2 (ранее): ARCHITECTURE.md, один транзакционный журнал на человека, двуязычная структура.
