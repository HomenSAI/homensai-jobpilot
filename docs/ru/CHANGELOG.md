# История изменений

[English](../../CHANGELOG.md) | [Русский](CHANGELOG.md)

Версия проекта записана в файле [VERSION](../../VERSION). Проект — это рабочий комплект для ИИ-агента, а не отдельное приложение поиска и отправки писем. Локальная страница статистики содержит HTML/CSS/JavaScript для показа и сортировки снимка.

Правила: `MAJOR.MINOR.PATCH`. MAJOR меняется, когда формат данных или правила изменились так, что старые данные не подходят. MINOR — новая функция или новая часть документации. PATCH — исправление или правка формулировок без новых возможностей. Каждое изменение в `main` добавляет строку сюда; номер повышается при выпуске. Каждый выпуск получает git-тег `vX.Y.Z`. **Правило языков (с версии 1.22.0, для всех репозиториев HomenS.AI):** каждая запись пишется сначала по-английски, а прямо под ней — тот же текст по-русски (блок `**English.**`, затем блок `**Русский.**`, у каждого свой список). Описание релиза на GitHub берётся из этого раздела, поэтому каждый релиз читается сначала по-английски, ниже по-русски. Одна и та же двуязычная запись есть в `CHANGELOG.md` и `docs/ru/CHANGELOG.md`. Записи до 1.22.0 остаются как были.

## 1.21.0 — 10.10.2026

**Русский.** Как распределить 44 места месяца, теперь решает сам человек: все в один день, по нескольку в день, в выбранные дни недели или в любом другом ритме. Человек называет это правило агенту своими словами; оно сохраняется дословно как `schedule.sending_rule_statement`, агент его никогда не выбирает, и без него план не составляется. Поэтому дневной максимум `max_per_day` теперь от 1 до 44 (44 — весь месяц в один день; 0 и 45 и больше отклоняются) и значения по умолчанию больше нет; за один запуск можно отправить больше двух писем (`max_per_run` от 1 до `max_per_day`, каждое в своё время или через интервал). Страницы обзора стали живее: стрелки между шагами, линия, соединяющая пронумерованные шаги, полоса прогресса чтения вверху, стрелка «к содержанию» под заголовком, блоки, появляющиеся при прокрутке, и карточки, приподнимающиеся под курсором; всё это отключается, если система просит меньше анимации. Месячный лимит 44 не изменился. Это изменение правила, поэтому номер минорной версии повышен.

- **Правила:** AGENTS, TODO_FOR_AI (A7, R02, план, проверка отправки), DATA_CONTRACT (§5, §13.1, §13.2), AI_BUILD_SPEC, ARCHITECTURE, ACCEPTANCE_TESTS (R02, CAD-02), USER_GUIDE (шаг 12), `examples/settings.example.json`; четыре редакции.
- **Страницы:** `assets/site.css`, `assets/site.js` (все страницы обзора); шаг «План» на обзоре и схема лимитов на странице архитектуры; четыре редакции.

## 1.3.1 — 07.10.2026

- Страница статистики: данные теперь лежат в отдельном файле `summary.js` рядом со страницей. Для реального профиля агент копирует `index.html` без изменений и пишет только `summary.js`, поэтому файл страницы никогда не правят, а ошибка в данных не может его сломать. Если `summary.js` нет или он некорректен, страница сообщает об этом. `summary.json` и блок данных внутри HTML убраны.
- Решение: скриптов-помощников нет. Скрипту нужна среда выполнения, которой нет на чистой Windows, подтверждение при каждом запуске, и он не может принудить то, что агент способен пропустить; подсчёт делается штатными командами системы (см. ARCHITECTURE.md), остальное — обычные файлы.
- Автоматический выпуск: `.github/workflows/release.yml` создаёт тег и релиз на GitHub при изменении `VERSION`. Работает только на серверах GitHub и не входит в продукт.
