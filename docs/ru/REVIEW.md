## Что не изменено

После ревизии пользователь утвердил название **HomenS.AI JobPilot**. В спецификации, README, руководстве и HTML-обзоре оно закреплено как окончательно выбранное, а имя будущего GitHub-репозитория — `homensai-jobpilot`. Это не подтверждение создания или публикации репозитория.

Авторство и фирменный стиль; агент и папка обязательны; Docker отменен; HTML только для просмотра; лимит 44; ближайшие цели приоритетнее; персональные CV/письма; независимые языки; нейтральный отчет; отдельное согласие на почтовые действия; запрет заимствования кода аналогов.

## Оставшиеся этапы — не выполненные функции

- Рабочая реализация инструментов, анкеты, статического дашборда и генератора документов.
- AGENTS.md, CLAUDE.md и TODO_FOR_AI.md после утверждения этапа реализации.
- Выбор и проверка конкретного Gmail-подключения; предоставление его точных параметров пользователю.
- Полный пользовательский путь для Claude Code; текущий подробный USER_GUIDE описывает Codex/Windows.
- Проверка приемочных сценариев, почтового восстановления и общего учета квоты.
- LICENSE, LICENSE-DOCS, NOTICE, подтверждение прав на релизные файлы и действительная ссылка на репозиторий.
- Видео: сейчас только сценарий, не MP4.

Добавленные .gitignore и образец JSON полезны уже сейчас, но не доказывают работу будущей системы. Тестовые сценарии не обозначены как PASS без реализации и evidence.
