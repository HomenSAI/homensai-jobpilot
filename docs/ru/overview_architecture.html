Архитектура

Правила и файлы: записи ведёт агент

Отдельного приложения для поиска работы и отправки почты нет. ИИ-агент следует правилам и ведёт локальные файлы. Страница статистики использует HTML/CSS/JavaScript только для проверки, сортировки, фильтрации и показа снимка, записанного агентом. Сервер, Docker и SQL-база не нужны.

01 · Части

Как устроены части вместе

Рабочий процесс выполняет агент, локальная страница статистики читает и показывает снимок. Она не выполняет почтовых действий.

У каждого человека один главный журнал — persons/<person_id>/journal/transactions-YYYY-MM.jsonl (monthly segments) — и файл-метка writer.lock, который существует, только пока пишет один чат. Реестры профилей, очередь, Status.txt и статистику можно пересобрать из этого журнала. Несколько профилей поиска делят один месячный лимит, а новый чат продолжает работу, не отправляя заявку повторно.

Защиты — лимит 44, «никогда не отправлять дважды», «один пишущий в каждый момент» — это порядок действий, которому агент обязан следовать, а не технические замки. Поэтому новая установка только готовит черновики, а автоматическая отправка требует явного принятия пользователем этого ограничения. Подробная архитектура · Контракт данных

Файлы с пометкой «запланировано» ещё не существуют. Имя папки Локальные_данные — фиксированный технический путь в обеих языковых редакциях. Это целевая структура, а не список готовых модулей.

03 · Работа

Правила работы

  • Основная работа идёт в локальном чате Codex или Claude Code. Список задач задаёт порядок действий; доказательства выполненного хранятся в журнале.
  • Первая настройка использует режим черновиков. Очередь хранится в папке и обрабатывается агентом.
  • Не более 44 отправок резюме на человека за календарный месяц — по всем профилям и каналам. Повторная отправка и замена после ошибки доставки занимают слот; последующий bounce слот не возвращает.
  • JobPilot блокирует свою 45-ю управляемую CV-подачу. Самостоятельные отправки пользователя квоту не расходуют. Ручной запасной способ для пакета JobPilot учитывается.
  • Отчёты показывают использованные, зарезервированные и оставшиеся слоты. Подготовленная папка или запланированная дата — не доказательство отправки.
  • Приглашения, положительные ответы и вопросы решает человек.
  • Подтверждённые ошибки доставки сохраняются. По умолчанию готовится не более одной подходящей новой компании как черновик; автоматическая замена требует отдельного разрешения для профиля.
  • Вопрос о ближайших свободных датах практики допускается только по утверждённым правилам профиля — после чтения всей цепочки и проверки, что такой вопрос ещё не задавали.
  • Месячный отчёт нейтральный, на выбранном языке, по шаблону пользователя, если он есть, и содержит отдельную страницу рыночных рекомендаций.
  • Письма Gmail не удаляются и не архивируются, метки не меняются.
  • Статическая HTML-страница показывает данные и сортирует строки. Личные документы и учётные данные никогда не публикуются на GitHub.
