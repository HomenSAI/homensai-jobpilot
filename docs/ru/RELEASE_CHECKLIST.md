# Контрольный список выпуска

Автор идеи и разработчик: Serhii Khomenko / HomenS.AI  
Применяется к выпускам исходников и документации HomenS.AI JobPilot.

Это ручная проверка перед публикацией. Текущий GitHub workflow создаёт выпуск при изменении VERSION в main, но сам этот список автоматически не проверяет. Перед отправкой обновления VERSION сопровождающий должен пройти пункты ниже.

## Перед публикацией

- [ ] Сверить репозиторий, ветку, родительский commit и планируемую версию.
- [ ] Просмотреть каждый изменённый файл и окончательный список файлов выпуска.
- [ ] Убедиться, что `Локальные_данные/`, реальные CV, сертификаты, данные почты, пароли, токены, сессии браузера, архивы и частные QA-материалы не входят в commit и архив.
- [ ] Проверить Git index и фактическое дерево выпуска. Одного `.gitignore` недостаточно для файлов, уже попавших в Git.
- [ ] Проверить кодовые секреты, пароли, реальные адреса и частные примеры. Автоматический сканер — это проверка, но не доказательство отсутствия всех личных данных.
- [ ] Проверить `LICENSE`, `LICENSE-DOCS` и `NOTICE`; сохранить обязательные уведомления PolyForm, ссылку CC BY-NC и уведомления о шрифтах IBM Plex SIL OFL.
- [ ] Убедиться, что новые материалы проекта сохраняют авторство Serhii Khomenko / HomenS.AI.
- [ ] Проверить актуальность README и обеих языковых редакций; корректно описывать статистическую страницу как HTML/CSS/JavaScript и не утверждать, что полный цикл агента/Gmail принят.
- [ ] Выполнить разрешённые проверки статистики и записать фактический результат. Они не заменяют приёмку агента, Gmail, Scheduled или браузера.
- [ ] Сверить VERSION и оба CHANGELOG. Изменение VERSION в main запускает существующий release workflow.
- [ ] Проверить локальные ссылки и обновлённые HTML в браузере. Для Word/PDF отдельно отрендерить и визуально проверить каждую страницу.

## Статус выпуска 1.5.0

- Регрессионные проверки страницы статистики: 18/18 прошли в изолированной JavaScript VM на синтетических данных.
- Полная визуальная проверка страницы в браузере: не выполнялась.
- Полная приёмка Codex-агента, Gmail-коннектора/браузера, фактического Gmail Scheduled и цикла DOCX/LibreOffice: не выполнялась.
- В release workflow нет автоматического fail-closed списка разрешённых файлов и проверки приватных данных; этот список ручной, его проходит сопровождающий.

Нельзя называть выпуск полностью принятым, пока обязательные сценарии остаются NOT RUN.
