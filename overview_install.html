Install

Installation, step by step

The setup takes about 30–40 minutes. Do the steps in order. Every step says what you should see on the screen, so you always know whether it worked. No Git, Python or other developer tools are needed on your computer.

Windows · ChatGPT Desktop · CodexClaude Code: compatibility not confirmedOne action per step
Order

What comes first: the agent or the archive?

First the agent, then the archive, then you connect the two. The agent comes first because its availability depends on your account: it is better to find out now than after you have prepared everything else. The archive is only a folder of files; it becomes useful when the agent opens it.

Part 1 · AgentInstall ChatGPT Desktop, sign in and make sure Codex is available. Step 1
Part 2 · Project folderDownload the project archive from GitHub in your browser and extract it into a folder. Step 2
Part 3 · Connect and startOpen the folder as a local project, set permissions and run the first safe start. Steps 3–6

You can gather your materials at any time, even before step 1 (see “Prepare your materials” below). In step 7 you tell the agent about yourself, in step 8 you connect mail (optional), in step 9 you check the first queue; steps 10–13 are optional features and the daily routine.

Package status. This is an experimental documentation-and-agent workflow. Statistics-page checks do not prove the complete Gmail/agent cycle. Verify the repository and release version before downloading: github.com/HomenSAI/homensai-jobpilot.

Before you start

What you need

Computer and accounts

  • A Windows computer with internet access.
  • ChatGPT Desktop and an account with Codex available. Codex access and usage limits vary by plan; verify current terms before purchase.
  • A separate job-search Gmail is recommended, only if you want mail tracking.

Your material

  • Your CV, diplomas and certificates in any format, if you have them — see “Prepare your materials” below.
  • Or just your voice: you can tell the agent about yourself and it writes everything down.
  • The languages for application documents and reports.
  • A dedicated folder for the project, for example Documents\HomenSAI-JobPilot.

Working with local files needs a local Codex project opened on your computer. An ordinary cloud ChatGPT project does not give access to a folder on your computer.

Prepare

Prepare your materials — you can do it first

The project ZIP contains a ready folder Локальные_данные\Положите_сюда (“put here”) with five subfolders. It is the only place where you have to put anything by hand. Fill it right after step 2, or gather the files now and copy them later. If you prepare nothing, the agent asks you everything itself (step 7).

FolderWhat to put there

CV and cover-letter templates

Everything about your CVs and letters goes into two folders. The agent works from it; the template you name is the one used for mailings.

  1. Put the material

    Everything about your CVs in 4_Шаблон_резюме, all your cover letters in 5_Шаблон_сопроводительного_письма. Any format, old versions too. Read only.

  2. Check the drafts

    The agent prepares a CV draft and a letter draft, with the source of every fact, and a list of older versions. You check them.

  3. Name the template

    Tell which CV and which letter you use now. That one becomes the template for mailings.

  4. Word copy and page check

    The template becomes an editable Word working copy in Resume or CoverLetter. Every page is compared with the original PDF: page count, size, text, position, pictures and fonts. You see the comparison before you approve it. A difference is reported, and the agent asks what to do.

No template yet?

  • the agent offers three layout variants to choose from
  • or you send your own template into folder 4 or 5

A photo on the CV

  • Only if you choose it: top right of the first page, 30 × 40 mm by default. You can choose another size; the proportions are kept.

The originals are never changed. The paths and checksums of the chosen templates are saved per profile; each new vacancy gets its own new documents.

Tell your story by voice

  1. Open a chat with Claude or ChatGPT and switch on voice mode (the microphone icon).
  2. Say: “I will tell you about myself for my CV. Ask me questions one topic at a time. At the end write down my story word for word, adding nothing, as a text file.” You can paste the questions from Вопросы_для_рассказа.md.
  3. Talk as long as you want, in parts, on different days, in any order. If you do not remember something, say so.
  4. Save the text file into 2_Рассказ_о_себе.

Or let the agent ask you

Prepare nothing. At step 6 start the agent in your project folder and say that you want to tell about yourself, by voice or in text. It asks the questions one topic at a time, saves your answers word for word into 2_Рассказ_о_себе and writes your knowledge base from them.

The agent only reads these folders; it never changes, moves or deletes your files. Everything stays on your computer and is not published (the folder Локальные_данные is excluded from Git). From your files and your story the agent writes your knowledge base: one file with your whole life story as facts (Локальные_данные\persons\<your id>\База_знаний\Жизнеописание.md). It shows you every fact for confirmation, and CVs and letters use only confirmed facts.

Part 1

The agent

  1. Install ChatGPT Desktop and sign in

    1. Open the official ChatGPT download page.
    2. Download and install the Windows version, start it and sign in.
    3. In the mode selector choose Codex. Do not choose a cloud ChatGPT project or Work: this workflow needs an open local folder.

    You should see: the main window with your account name and a mode selector that includes Codex.

    If Codex is missing: check whether it is available for your account and organization. Do not install unofficial builds. See OpenAI’s Quickstart.

Part 2

The project folder

  1. Download and extract the project archive

    1. Open the project repository on GitHub (github.com/HomenSAI/homensai-jobpilot) in your browser.
    2. Choose Code → Download ZIP.
    3. In File Explorer create a folder such as Documents\HomenSAI-JobPilot.
    4. Extract the ZIP into that folder.
    5. Do not extract into a Windows system folder.

    You should see: in the folder, directly (not inside another folder): README.md, USER_GUIDE.md, AI_BUILD_SPEC.md, AGENTS.md, CLAUDE.md, TODO_FOR_AI.md, dashboard_template and the folder Локальные_данные\Положите_сюда with five subfolders.

    If the files are one level deeper: you extracted into an extra subfolder. Move the contents up, or pick the inner folder in step 3.

    The folder will hold both the project instructions and your local working data. Personal profiles, CVs, emails, OAuth tokens and statistics must never be published on GitHub.

Part 3

Connect the agent to the folder and start

  1. Create a local project and choose the folder

    1. Open Projects in Codex.
    2. Choose Add local project or Open folder (the exact name depends on the version).
    3. Select the full path of the extracted folder, for example C:\Users\YourName\Documents\HomenSAI-JobPilot.
    4. If a project already exists: its menu → Edit project → Add folder, select the folder and choose Make primary.
    5. Name the project, for example Job search.

    You should see: the project in the list, and as its primary folder the one that contains README.md — not a single file and not a parent folder with unrelated data.

    Important: writing “work at path …” in a chat is not enough. The folder must be opened or attached as the project’s local folder. See local projects.

  2. Create a setup chat

    1. Open your new local project and choose New chat inside it.
    2. Check that Codex and the local environment (Local / This computer) are selected, not Cloud or Worktree.
    3. Name the chat, for example Initial JobPilot setup.

    You should see: a chat inside the project with “Local” shown next to the composer.

    You may use separate chats for setup, searching, daily checks and monthly reports. The project’s files and journal keep the state between chats; do not rely on one conversation’s history.

  3. Set the permissions

    1. Open the permissions menu below the message box and choose Ask for approval. The agent can then work in the current folder and asks before anything else.
    2. If the setting is missing, look under Settings → General → Permissions.
    3. Do not choose Full access, do not run ChatGPT Desktop as administrator and do not give access to the whole drive.
    4. If Codex asks for access outside the folder, stop and ask yourself whether it is really needed. Grant only a narrow, one-time permission.
    5. Web search, files, mail and screen control are separate permissions. Allowing one does not allow the others.

    You should see: “Ask for approval” (or the equivalent) in the permissions menu, and the project folder as the working folder.

    Official explanations: permission modes, sandboxing.

  4. Make the first safe start

    Type this into the new chat (or simply “Start”):

    Start. Read AGENTS.md, TODO_FOR_AI.md and OPERATING_REQUIREMENTS.md in the project folder and lead me through the first setup. Ask one question at a time and explain in simple words. Work only in the project folder. Until I check the materials and allow sending, do not send anything and do not put anything into Gmail "Scheduled".

    The agent loads its rules by itself (Codex reads AGENTS.md, Claude Code reads CLAUDE.md). It introduces itself, confirms the working folder, checks its tools and then asks you, one question at a time: your name and the language you prefer. Then it asks for your consent to read your personal materials and starts the first setup (step 7). Answer in your own words, by voice if your app has the microphone button.

    You should see: the agent names the correct folder, explains in a few lines what will happen, says that it works in draft-only mode and asks its first question.

    If the agent does not know what to do, or says that AGENTS.md or TODO_FOR_AI.md is missing: the folder is the wrong one or the archive is incomplete. Check steps 2 and 3. Do not ask the agent to invent the missing files.

Part 4

Your data, mail and the first queue

  1. The first setup: the agent asks, you answer

    From here the agent leads. There is no form: it asks one question at a time and saves every answer to files. The order is always the same:

    1. Consent. Before it reads anything personal, it explains that a cloud agent may pass what it reads to its provider, and asks your consent. “Stored locally” does not mean “processed offline”. You can say no and start with an anonymized example.
    2. Your story. It tells you where your story belongs: the folder Локальные_данные\Положите_сюда\2_Рассказ_о_себе. If you have none, it offers to prepare it right now, completely by voice: switch on the microphone and talk about your whole life. It does not interrupt and saves every word.
    3. Your documents. It asks whether you have a CV, diplomas, certificates, course records or references. Put all of them into 1_Мои_документы (photos and scans are fine) and say “ready”. No documents? Say so, and you continue.
    4. Analysis. It reads everything and writes your knowledge base. Then it asks about what is missing, one topic at a time: certificates, courses, language levels, skills, real situations, the driving licence and a car.
    5. Confirmation. It shows the facts section by section. For each say: right, correct it or wrong. It never invents experience, dates, certificates or language levels. A fact without a document stays valid, marked “self-reported”.
    6. The search. It asks what we are looking for (job, Ausbildung, internship, Probearbeit, temporary work), which roles and industries, where you live, the radius in kilometres, how you get there (car, train, bus or tram, bicycle, on foot — any combination), how long the way may take, transfers, walking and the evening return, preferred towns, the languages of the CV, the letter, the email and the report (separately), how to spread the applications, and whether you have a report template (3_Шаблон_отчёта).
    7. Saved. It repeats all your answers; you say “right”. The first setup is finished, and from now on it works from these saved files.

    You should see: the file Локальные_данные\persons\<your id>\База_знаний\Жизнеописание.md with your life story as facts, each marked confirmed or self-reported, and the file Локальные_данные\profiles\<direction>\profile.json with your search settings. You can open and read both in any text editor.

    Never put passwords, one-time codes or OAuth tokens into any file. Private notes stay marked as sensitive and never go into a CV without your explicit choice. Check that Локальные_данные/ is excluded from publication. Several search directions of one person share one limit of 44 submissions per month.

  2. Connect Gmail through an approved connector or the built-in browser

    1. Ask the agent which Gmail options are available in your Codex installation. Choose an existing official approved connector or the built-in Browser; do not add an arbitrary server.
    2. For a connector, follow its official sign-in flow. For Browser, ask Codex to open https://mail.google.com and tell it not to read or send yet; then sign in yourself and check the Gmail profile address.
    3. For Browser, open Settings → Browser → Agent permissions. If Computer Use is required, enable it from Codex → Plugins → Computer Use and allow only the browser. For a connector, verify the account and separate read/send permissions.
    4. Begin with read-only checks. Sending and scheduling need separate approval. Never allow deleting, Gmail-archiving, moving messages or changing labels.

    You should see: the exact Gmail address you intended. The browser session may expire; it is not a token stored in the project.

    Attachments: the built-in browser cannot automate file uploads; an approved connector may support them, but verify this. If not, attach the CV and cover letter yourself and check them in Gmail. If neither route works, use EMAIL_TO_SEND.txt and File Explorer. See built-in browser and Computer Use.

  3. Prepare and review the first queue

    1. Ask the agent to find companies and vacancies within your radius and to collect sources, contacts, requirements and check dates.
    2. Review the records, duplicates, addresses and whether the vacancies are still open. Check the real routes for your transport.
    3. Ask for a tailored document package in the chosen language, then check every date, fact, recipient and attachment.
    4. Review the queue and confirm the dates and intervals. Do not enable bulk mailing.
    5. The system allows at most 44 CV submissions per person per calendar month. If the remaining allowance cannot be verified, the agent must stop.
    6. Use draft mode before sending anything. Sending is allowed only after the profile has been configured and the specific message checked.

    You should see: drafts in the month folders and a queue with exact dates and a remaining-slots counter.

    If the agent reports “sending outcome unknown”, do not just ask it to send again: first compare with the SENT folder or the portal confirmation. Changing an attachment or recipient needs a fresh review. The default subject limit is 50 characters including spaces; this is a product rule, not a mail-service limit.

Part 5

Optional features and daily work

  1. Enable screen control only if needed

    Searching and managing files do not normally need mouse control. If one task really needs a browser or another window:

    1. In ChatGPT Desktop open Codex → Plugins → Computer Use and install or enable it if your version has it.
    2. Open Settings → Computer Use and allow only the application you need.
    3. On Windows keep the controlled window visible on the active desktop.
    4. Approve only actions you understand. Computer Use does not replace OAuth, folder access or consent to send.

    See Computer Use. The basic workflow does not need it.

  2. Daily work and scheduling

    For a manual check, open the local project, start a Daily check chat and ask the agent to read the rules and do the next safe plan item. The default is every day at 16:00 in your time zone. At the beginning of a new month the agent asks once whether to prepare that month's packages and schedule.

    You can ask ChatGPT Desktop/Codex to create a recurring task for the same local project. Verify it appears in Scheduled and inspect its first result. For local files, keep the computer on, ChatGPT Desktop running and the folder available. On Windows, Computer Use needs the target browser visible and may take over the foreground. If a recurring task or browser access is unavailable, run the check manually. See Scheduled tasks.

    Missed submissions are not sent as a catch-up batch. Gmail Scheduled messages may still send independently of the agent.

  3. Open your statistics and build a report

    1. After a check, open Локальные_данные\dashboard\index.html, the local profile menu. Each profile has Statistics and Readiness links. No server is needed.
    2. Statistics show years, months and days, with date/result sorting and filters. Readiness shows checked setup items, the 0–100% gauge and private links to your documents. Both are read-only; the agent updates them.
    3. At the end of the period ask the agent for DOCX/PDF files in the chosen language and template. Without your own template it uses the neutral monthly table. The agent must render the DOCX, inspect every page and export the matching PDF.
    4. Check your name, reporting period, rows and the brief reason for each reply. Applications without a reply say “no response received” in the report language.
    5. The report is saved locally. Daily email delivery to you is an optional, separately approved setting; reports are not sent to employers or authorities without a separate instruction.

    Statistics distinguish the number of reply messages from the number of applications that received a reply. A reply to an older application counts in the month it arrived. A rejection without a reason reads “reason not specified”. A separate PDF page holds a market recommendation with date, radius, transport, verified sources and coverage; unavailable estimates are marked as such.

  4. Update the package and back up your data

    Before updating, copy Локальные_данные/ to a separate backup folder. Download the new ZIP into a new folder, compare versions and instructions, and ask the agent to migrate only confirmed settings. Never extract an update over your personal data and never publish Локальные_данные/.

Scope

What is not implemented

JobPilot is an experimental set of prompts and written procedures for an external AI agent, not a standalone job-search or mail-sending application.

Workflow code

Search, document preparation, Gmail handling, scheduling, archiving and reporting are instructions, not guaranteed software mechanisms. There is no SMTP service, background sender, database server or hard technical monthly quota lock.

Statistics-page exception

The local statistics view contains HTML/CSS/JavaScript to display, sort and filter an agent-prepared snapshot. It does not search, send or schedule mail, or change files.

Your decision and responsibility

You decide whether to use the experimental workflow. Review and approve every external action. Prompts are editable text: you are responsible for reviewing changes and resulting messages/documents. Verify completion in Gmail and local files. The package does not guarantee accurate research, delivery, replies or employment; the full cycle has not been tested on every agent/account.

CV and cover-letter templates

Put everything about your CVs into 4_Шаблон_резюме and all your cover letters into 5_Шаблон_сопроводительного_письма (any format). The Word working copy of the template you name is made after the page check; it appears in Resume/ and CoverLetter/. The original sample is never changed. The conversion is checked page by page against the PDF (page count, size, text, position, pictures and fonts), and you see the comparison before you approve it. If a page differs or the check cannot be made, the agent reports the difference and asks what to do. The exact selected paths/hashes are saved per profile; new vacancies receive new document files.

Help

If something does not work

The agent cannot see the files

Check that a local project is open and its primary folder is the extracted root. A path in a message is not enough.

The agent cannot save a result

Check the permission mode and access to the project folder. Do not open access to the whole drive.

Gmail or attachments are unavailable

For a connector, check its availability, intended account and read/send permissions; for Browser, check Browser and Computer Use permissions. If neither route works, use EMAIL_TO_SEND.txt and the manual fallback. Do not paste credentials into chat. Verify Scheduled or SENT before marking completion.

A rules or template file is missing

The archive may be incomplete, or still a design build. Do not ask the agent to invent files.

Statistics will not open

Check that the agent generated Локальные_данные/dashboard/profiles/<profile_id>/index.html; the clean template contains only sample data.
