# 4_CV_Templates — CV templates · RU: Шаблоны резюме · DE: Lebenslauf-Vorlagen · UK: Шаблони резюме

**RU.** Сюда кладите всё, что есть о ваших резюме: действующее, старые версии, любые форматы (DOCX, PDF, текст, фото, сканы). Оригиналы не меняются. Агент читает всё, готовит из этого черновик резюме и список фактов из старых версий и просит вас проверить. Если одно из резюме вы используете сейчас, скажите какое: оно станет шаблоном для рассылок. Фото попадает в резюме только по вашему выбору. Если шаблона нет, агент предложит три варианта оформления на выбор или вы присылаете свой шаблон сюда.

**EN.** Put here everything you have about your CVs: the current one, old versions, any format (DOCX, PDF, text, photos, scans). The originals are never changed. The agent reads everything, prepares a CV draft and a list of facts from the old versions, and asks you to check them. If you use one of the CVs now, tell which one: it becomes the template for mailings. A photo goes into the CV only by your choice. Without a template the agent offers three layout variants to choose from, or you send your own template here.

**DE.** Legen Sie hier alles ab, was Sie zu Ihren Lebensläufen haben: den aktuellen, alte Fassungen, jedes Format (DOCX, PDF, Text, Fotos, Scans). Die Originale werden nie verändert. Der Agent liest alles, erstellt daraus einen Lebenslauf-Entwurf und eine Liste der Fakten aus den alten Fassungen und bittet Sie um Prüfung. Nutzen Sie einen der Lebensläufe jetzt, nennen Sie ihn: Er wird zur Vorlage für Versände. Ein Foto kommt nur auf Ihren Wunsch in den Lebenslauf. Ohne Vorlage bietet der Agent drei Layoutvarianten zur Auswahl an, oder Sie senden hier Ihre eigene Vorlage.

Personal files remain private; only this README is included in the public package.
