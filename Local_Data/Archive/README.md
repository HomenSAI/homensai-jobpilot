# Archive — daily archive · RU: Архив · DE: Archiv · UK: Архів

**EN.** Every day the agent puts here one full copy of your JobPilot data: a folder named `<YYYY-MM-DD>_daily` (for example `2026-10-10_daily`). With it you can rebuild everything if your computer breaks or is lost. **Copy the newest folder (or this whole `Archive` folder) to a USB stick or another disk regularly**, for example once a week. The statistics page reminds you and has a link to this folder. To restore, give the folder to the agent and ask it to restore from the archive: it checks the copy first and sends nothing until everything is reconciled.

**RU.** Каждый день агент кладёт сюда одну полную копию ваших данных JobPilot — папку `<ГГГГ-ММ-ДД>_daily` (например, `2026-10-10_daily`). По ней можно восстановить всё, если компьютер сломается или пропадёт. **Регулярно копируйте самую свежую папку (или всю папку `Archive`) на флешку или другой диск**, например раз в неделю. Страница статистики напоминает об этом и даёт ссылку на эту папку. Чтобы восстановить систему, покажите папку агенту и попросите восстановить из архива: он сначала проверит копию и ничего не отправит, пока всё не сверено.

**DE.** Jeden Tag legt der Agent hier eine vollständige Kopie Ihrer JobPilot-Daten ab: einen Ordner `<JJJJ-MM-TT>_daily` (zum Beispiel `2026-10-10_daily`). Damit lässt sich alles wiederherstellen, wenn der Computer kaputtgeht oder verloren geht. **Kopieren Sie den neuesten Ordner (oder den ganzen Ordner `Archive`) regelmäßig auf einen USB-Stick oder eine andere Festplatte**, zum Beispiel einmal pro Woche. Die Statistikseite erinnert daran und verlinkt diesen Ordner. Zum Wiederherstellen zeigen Sie dem Agenten den Ordner und bitten ihn darum: Er prüft die Kopie zuerst und versendet nichts, bis alles abgeglichen ist.

**UK.** Щодня агент кладе сюди одну повну копію ваших даних JobPilot — теку `<РРРР-ММ-ДД>_daily` (наприклад, `2026-10-10_daily`). З нею можна відновити все, якщо комп’ютер зламається чи загубиться. **Регулярно копіюйте найсвіжішу теку (або всю теку `Archive`) на флешку чи інший диск**, наприклад раз на тиждень. Сторінка статистики нагадує про це й дає посилання на цю теку. Щоб відновити систему, покажіть теку агентові й попросіть відновити з архіву: він спершу перевірить копію й нічого не надішле, доки все не звірено.

Personal data: everything in this folder except this README stays on your computer and is never published.
