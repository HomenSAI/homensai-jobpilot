# dev/ — notes for the developer

These files are working notes for the person (and the AI session) who develops HomenS.AI JobPilot: the open work, the hand-over to the next development session, decisions still to be made.

**They are not instructions for users and not for the AI agent that runs a person's job search.** An agent working in a person's JobPilot folder ignores this folder; its instructions are `AGENTS.md`, `TODO_FOR_AI.md` and `OPERATING_REQUIREMENTS.md` at the root.

- `REMAINING_WORK.md` — what still has to be done or decided.
- `NEXT_SESSION.md` — hand-over for the next development session.
