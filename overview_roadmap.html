02 · Version 1.5.0

What version 1.5.0 changes

Prepare the month ahead

At the start of each month the agent asks once whether to prepare the target list, tailored CVs and cover letters, email bodies and a consented monthly schedule. The 44-CV limit remains shared across a person's profiles.

Gmail and recovery

The user chooses an available, approved connector or the built-in browser and signs in personally. Scheduling is recorded only after the message is verified in Gmail Scheduled. The built-in browser cannot automate file uploads; a connector may or may not, so the capability must be verified. Local archives are created after mail operations; lost archives trigger read-only Gmail reconciliation.

Daily checks and reports

The default check is daily at 16:00 local time, subject to a real scheduled-task capability. Daily reports to the user are opt-in. Monthly DOCX/PDF reports use a user template or a neutral table, with visual page checks.

Statistics and privacy

The page rejects malformed or duplicate snapshots, preserves month-end history, shows empty months, never invents a shared quota total, and sorts employer rejections before technical delivery failures. The release still requires full agent/browser acceptance.

03 · Version 1.4

What version 1.4 changes

The agent starts by itself

AGENTS.md, CLAUDE.md and TODO_FOR_AI.md are in the package. You open the folder and say “Start”; the agent introduces itself and asks one question at a time.

Ready folders for your files

Three folders in Локальные_данные\Положите_сюда: documents, your story, report template. You put things there before or after the first run.

A knowledge base instead of a form

Your whole life story as confirmed facts in one readable file, written from your files and from an interview by voice or text.

04 · Version 1.3

What version 1.3 changed

No standalone application

The search and mail workflow is carried out by the AI agent using written procedures and local files. The statistics page uses HTML/CSS/JavaScript only to validate, sort, filter and display the agent-written snapshot. Journal and quota safeguards remain procedural.

One journal per person

Every completed action is one line in a single journal, written under a marker file writer.lock. Several profiles never keep competing journals. Everything else can be rebuilt from it.

Honest safeguards

The limit of 44 and “never send twice” are procedures, not technical locks. Drafts and approval of each message come first; automatic sending is off by default.

Earlier rules still apply: three replies to one application count as three events but one application with a reply, and a late reply belongs to the month in which it arrived. Reports keep their revisions. The acceptance scenarios are checked by hand in a chat; having scenarios does not mean that they have been passed.
