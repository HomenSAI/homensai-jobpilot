02 · Version 1.3

What version 1.3 changes

No program

The project is rules and files only. Scripts and local commands were removed from the design: the agent keeps the journal and the limit by following written procedures.

One journal per person

Every completed action is one line in a single journal, written under a marker file writer.lock. Several profiles never keep competing journals. Everything else can be rebuilt from it.

Honest safeguards

The limit of 44 and “never send twice” are procedures, not technical locks. Drafts and approval of each message come first; automatic sending is off by default.

Earlier rules still apply: three replies to one application count as three events but one application with a reply, and a late reply belongs to the month in which it arrived. Reports keep their revisions. The acceptance scenarios are checked by hand in a chat; having scenarios does not mean that they have been passed.
