What exists

Finished

  • The rules for the agent: specification, architecture, data contract and acceptance scenarios, in English, Russian, German and Ukrainian.
  • The instruction files for the agent as drafts (AGENTS.md, CLAUDE.md, TODO_FOR_AI.md), the ready folders for your materials and the knowledge base format.
  • This illustrated overview and the step-by-step installation guide.
  • The statistics page: validated snapshots, historical cutoffs, empty months, shared quota display and result sorting. A local VM regression run reports 18 targeted checks passing; this is not a full browser/agent test.
  • Operating requirements for monthly preparation, Gmail Scheduled/manual fallback, archives, daily checks/reports, readiness and reporting; separate code and documentation license notices.

Not done yet

  • Trying the instruction files for the agent (AGENTS.md, CLAUDE.md, TODO_FOR_AI.md) in practice: with someone who prepared nothing, with someone who filled the folders, and with a voice interview.
  • Checking a Gmail connection and its exact setup.
  • Performing the acceptance scenarios by hand, on synthetic data.
  • Full real-user acceptance of the agent workflow, Gmail, document rendering and scheduling.
  • Automated release/privacy gate and complete setup verification in Claude Code.

What remains to be done

  • Try the instruction files in Codex and in Claude Code and correct what the agents misunderstand.
  • A first full trial on synthetic data, by hand in a chat: profile → target → package → plan → simulated reply → report and offline HTML.
  • Checks of interrupted work and of two chats writing at once.
  • Then Gmail reading and controlled sending with proof checks. Each profile chooses draft mode, approval of each message, or — with the limitation accepted — an automatic queue.
  • Vacancy and route sources and their terms of use.
  • Scheduled agent runs where available; manual resumption must work on its own.
  • Rights and privacy checks before publication.
