# CV working documents / Рабочие документы резюме / Lebenslauf-Arbeitsdokumente

**RU.** Рабочая папка. Сюда агент пишет черновик резюме, подготовленный из `4_Шаблон_резюме/`, и Word-копию того шаблона, который вы назвали. Из PDF-шаблона Word-копия создаётся только после вашего выбора, сравнивается с исходным PDF страница за страницей, и результат вы подтверждаете. Исходные файлы не перезаписываются. Недоступная или непроверенная конвертация не считается готовым шаблоном.

**EN.** Working folder. The agent writes here the CV draft prepared from `4_Шаблон_резюме/` and the Word copy of the template you named. A Word copy of a PDF template is made only after your choice; it is compared with the original PDF page by page, and you approve the result. The sources are never overwritten. An unavailable or unchecked conversion is not a usable template.

**DE.** Arbeitsordner. Hier schreibt der Agent den aus `4_Шаблон_резюме/` erstellten Lebenslauf-Entwurf und die Word-Kopie der von Ihnen genannten Vorlage. Eine Word-Kopie eines PDF-Musters entsteht erst nach Ihrer Wahl, wird Seite für Seite mit dem Original-PDF verglichen, und Sie bestätigen das Ergebnis. Die Quellen werden nie überschrieben. Eine nicht verfügbare oder ungeprüfte Konvertierung ist keine nutzbare Vorlage.
