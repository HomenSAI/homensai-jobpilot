# Resume / Lebenslauf / Резюме

**RU.** Сюда кладём шаблон резюме — свой образец в Word (.docx) или PDF. Если шаблон в PDF, агент сам переводит его в Word-документ и сохраняет этот Word-файл в эту же папку (исходный PDF не меняется). Если шаблона нет, агент создаёт нейтральный шаблон при первой настройке. Резюме корректируется: шаблон можно заменить в любой момент, новая версия становится основой для следующих резюме.

**EN.** Put your resume template here: your own sample as Word (.docx) or PDF. If it is a PDF, the agent converts it into a Word document and saves that Word file in this same folder (the PDF stays unchanged). If there is no template, the agent creates a neutral one during the first setup. The resume is revised over time: replacing the template changes the base for later resumes.

**DE.** Legen Sie hier Ihre Lebenslauf-Vorlage ab: Ihr Muster als Word (.docx) oder PDF. Bei einer PDF-Datei wandelt der Agent sie in ein Word-Dokument um und speichert es in diesem Ordner (die PDF-Datei bleibt unverändert). Ohne Vorlage erstellt der Agent bei der Ersteinrichtung eine neutrale Vorlage. Der Lebenslauf wird laufend überarbeitet.
