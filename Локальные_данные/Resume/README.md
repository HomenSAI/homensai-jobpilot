# CV layout template / Шаблон оформления резюме / Lebenslaufvorlage

**RU.** Сохраните здесь свой образец DOCX или PDF. Исходный файл не перезаписывается. Для PDF агент создаёт рядом отдельный редактируемый DOCX, сравнивает каждую страницу с источником и просит утвердить результат. Недоступная или непроверенная конвертация не считается готовым шаблоном. Шаблон задаёт дизайн, а подтверждённая база знаний — содержание; для каждой вакансии создаётся новое резюме. Если образца нет, предлагается нейтральный шаблон из `examples/templates/`. Для разных людей выбираются отдельные подпапки по `person_id`; активные пути и хеши сохраняются в профиле.

**EN.** Put your DOCX or PDF sample here. The source is never overwritten. For PDF, the agent creates a separate editable DOCX beside it, compares every page with the source and asks you to approve it. An unavailable or unchecked conversion is not a usable template. The template provides design; confirmed knowledge-base facts provide content. Each vacancy gets a new CV. Without a sample, the neutral template from `examples/templates/` is offered. Different people use separate `person_id` subfolders; active paths and hashes are saved in the profile.

**DE.** Legen Sie hier Ihr DOCX- oder PDF-Muster ab. Die Quelle wird nie überschrieben. Aus PDF erstellt der Agent eine eigene bearbeitbare DOCX daneben, vergleicht jede Seite mit der Quelle und bittet um Freigabe. Eine nicht verfügbare oder ungeprüfte Konvertierung ist keine nutzbare Vorlage. Die Vorlage liefert das Design; bestätigte Fakten der Wissensbasis liefern den Inhalt. Jede Stelle erhält einen neuen Lebenslauf. Ohne Muster wird die neutrale Vorlage aus `examples/templates/` angeboten. Verschiedene Personen nutzen getrennte `person_id`-Unterordner; aktive Pfade und Hashes werden im Profil gespeichert.

Personal files remain private; only this README is included in the public package.
