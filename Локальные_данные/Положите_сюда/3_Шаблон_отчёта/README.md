# 3_Шаблон_отчёта / Report template

**RU.** Нужна только если у вас есть свой образец отчёта (например, для биржи труда или куратора). Положите сюда файл-образец. Агент работает с копией, а оригинал не меняет; из отчёта убираются названия организаций и номера дел. Нет шаблона — оставьте папку пустой: агент составит простую нейтральную таблицу.

**EN.** Only if you have your own report sample. Put the file here. The agent works on a copy and never changes the original; names of agencies and case numbers are removed from the result. No template: leave the folder empty and the agent makes a simple neutral table.
