# 5_Шаблон_сопроводительного_письма / Cover letter material

**RU.** Сюда кладите все сопроводительные письма, которые у вас есть, в любых форматах и версиях. Оригиналы не меняются. Агент читает их, готовит черновик письма с источниками фактов и список старых версий и просит вас проверить. Если одно из писем вы используете сейчас, скажите какое: оно станет шаблоном для рассылок. Если шаблона нет, агент предложит три варианта оформления на выбор или вы присылаете свой шаблон сюда.

**EN.** Put here all the cover letters you have, in any format and version. The originals are never changed. The agent reads them, prepares a letter draft with the sources of the facts and a list of older versions, and asks you to check them. If you use one of the letters now, tell which one: it becomes the template for mailings. Without a template the agent offers three layout variants to choose from, or you send your own template here.

**DE.** Legen Sie hier alle Anschreiben ab, die Sie haben, in jedem Format und jeder Fassung. Die Originale werden nie verändert. Der Agent liest sie, erstellt einen Anschreiben-Entwurf mit den Quellen der Fakten und eine Liste der alten Fassungen und bittet Sie um Prüfung. Nutzen Sie eines der Anschreiben jetzt, nennen Sie es: Es wird zur Vorlage für Versände. Ohne Vorlage bietet der Agent drei Layoutvarianten zur Auswahl an, oder Sie senden hier Ihre eigene Vorlage.
