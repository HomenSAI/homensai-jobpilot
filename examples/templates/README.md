# Neutral templates (English)

These files are neutral starting points. They contain no personal data, no logos and no employer names. Each Word file has a PDF exported from it with LibreOffice.

| Files | Use |
|---|---|
| `Resume_neutral_EN.docx` / `.pdf` | One-page resume, A4, Arial 11 pt, headings 13 pt |
| `CoverLetter_neutral_EN.docx` / `.pdf` | One-page cover letter, same header, font and margins as the resume |
| `Report_neutral_EN.docx` / `.pdf` | Monthly report, A4 landscape, table text 12 pt; used when the person has no report template of their own |

## How to use

1. The person may replace these with their own template. The resume and letter go into `Локальные_данные/Resume/` or `Локальные_данные/CoverLetter/` (a PDF is converted to Word in the same folder). A report template goes into `Локальные_данные/Положите_сюда/3_Шаблон_отчёта/`.
2. Replace every text in square brackets, and delete the lines that are not needed. Enter only facts that are confirmed; do not add date of birth, photo or family data unless the person chooses to.
3. The cover letter subject line must not exceed 50 characters.
4. The texts are in English. The resume, cover letter, e-mail and report languages are chosen separately during setup; for another language the agent prepares a neutral template in that language.
5. The agent renders the Word file to PDF with the tools it has (LibreOffice or Word) and looks at every page. A page counts as checked only after it has been viewed, and the PDF is exported from the checked Word file. A page count alone does not confirm the layout.
6. The DOCX names Arial. The PDFs were rendered with a metric-compatible substitute (Liberation Sans), so line breaks match Arial.
